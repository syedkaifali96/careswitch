# Published CareSwitch presentation

Updated 10 October 2026. [Watch on YouTube](https://youtu.be/PYqF6pDfuLU): uploaded **Unlisted**, playback checked, and the link saved in Devpost. Anyone with the link can view. Devpost final submission remains paused.

The video is approximately **176.7 seconds (2:57)**, 1920 × 1080, 24 fps, H.264/AAC MP4. [The same MP4](CareSwitch-demo.mp4), [English SRT](CareSwitch-demo-en.srt), [English VTT](CareSwitch-demo-en.vtt) and [timed narration](demo-script.md) are included in the ZIP.

It uses edited actual app captures from mouse practice mode, with diagrams, close-ups, subtle zooms and fades. It is not a continuous screen recording and contains no live head-control footage or participant webcam recording. The camera flow diagram is an explanation. Phone imagery is a responsive browser capture, not a physical-phone trial.

Narration was generated locally with the installed Microsoft Zira Desktop voice. English captions are burned into the picture and are always visible; a separate selectable YouTube caption track has not been uploaded. Neither narration nor presentation proves all app languages sound correct.

This version supersedes the earlier 2:50 screenshot-walkthrough draft. It shows the purpose, board, draft/Confirm workflow, languages, settings and limits. A future voluntary real head-control recording could strengthen the presentation; it is not included in this version or established here as an official additional requirement.
